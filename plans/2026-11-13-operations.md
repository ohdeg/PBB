# PBB 운영 관측
- 외부 GitHub Actions 러너가 운영 웹과 API health를 주기적으로 검사한다. 연속 실패/복구 상태 전환만 Discord에 전송하고 성공적으로 전달된 상태만 보관한다. 비밀은 GitHub Actions secret으로만 구성한다.
- Spring MVC 완료 시 실제 5xx만 앱·정적 핸들러·상태·서울 날짜별로 집계한다. 경로 매개변수, 본문, 이메일, 오류 메시지는 저장하지 않는다. 기록 실패가 원 요청을 바꾸지 않게 한다.
- 등급·추천 앱의 실제 변경과 이력은 한 MySQL 트랜잭션으로 저장한다. 조회는 기존 DEV 권한과 현재 계정 등급을 모두 검사하고, 서울 일자 경계, 최근순 페이지, 비캐시 응답을 사용한다.
- 기존 프로필 DEV 패널에 오늘의 오류/이력과 새로고침·접근 가능한 상태를 추가한다. 로컬 Flyway, 신규 초기화 SQL, 운영 수동 SQL을 맞춘다.
- 검증: 외부 감시 상태 전이/웹훅 실패, 권한·날짜 경계·집계 및 감사 기록, 프론트 타입/린트/빌드와 반응형 브라우저 검증. 사용자 DB와 실제 알림 채널로 테스트하지 않는다.
