## 섭취 `/meals` ★변경

```
섭취

끼니  [아침] [점심] [저녁] [간식]   ← 선택 후 추가

오늘 먹은 것
  [________________________]  [추가]
  예: 닭가슴살 150g

── 오늘 큐 ──
아침
  · 계란 2개          [×]
  · 토스트            [×]
점심
  · 닭가슴살 150g     [×]
저녁
  · 현미밥, 육개장    [×]
간식
  · 바나나            [×]

[ 오늘 마감 · 분석 ]   ← Gemini 일괄 (동의 필요)
  ※ 다음날 앱 열면 어제 미마감 큐 자동 분석

── 분석 결과 (마감 후) ──
1478 kcal · 탄 180 · 단 95 · 지 42
한줄평: 단백질은 충분하고 탄수는 목표보다 약간 높아요.
```

마감: JSON → Gemini → `dieta_intake_logs`.
요청에 `goalHint`(목적·유지kcal·일일목표) + `activityHint`(steps·activeMinutes 항상;
`activityKcal`은 유저 입력 시에만) + `estimateActivityKcalIfMissing` 포함.

## 체크인 `/check-in`

```

[다음 주 계획 보기] → 모달
  · 유지 — 일일/W/활동 목표 유지 (체중 X 조정 무시)
  · 체중 기준 조정 — 기존 Δ→X→처방
  ※ 체중은 그대로여도 비체중 신호에 변동이 있으면 유지를 선택하셔도됩니다.
※ 목표 체중 도달 시 유지 모드 자동 전환 (설정에서 유지 토글로 해제 가능)
```
